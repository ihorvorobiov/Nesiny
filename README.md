# 🎉 Birthday Quest Landing Page (SPA)

Інтерактивний лендинг-квест до Дня народження для Альони та її чоловіка Діми.

## 🚀 Маршрутизація
- **Потік для Альони (старт квесту)**: `index.html` (або `?player=alona`)
- **Потік для Діми (покерний стіл)**: `index.html?player=dima`

## 📁 Структура
- `index.html` — головна сторінка SPA
- `css/styles.css` — стилі та анімації (Glassmorphism / Neomorphism)
- `js/runner.js` — 2D Canvas міні-гра «Святковий забіг конячки»
- `js/poker.js` — інтерактивний покер Texas Hold'em
- `js/audio.js` — синтез звуків Web Audio API
- `js/app.js` — логіка квесту та валідація PIN-коду `0810`
